# Kayros Music – Presskit interattiva

Presentazione interattiva di Kayros Music (IT/EN). Tutto è contenuto nel solo file `index.html` (immagini, font, stili e script inclusi): non servono altre cartelle.

## Pubblicazione su GitHub Pages
1. Carica `index.html` (e `.nojekyll`) nella radice del repository.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Il sito sarà su `https://<nome-utente>.github.io/<nome-repository>/`.
